# lens-core-bugfix

This skill is registered as a public Lens command surface. The implementation is intentionally delegated to the installed Lens runtime so module validation can verify that the help entry and prompt registration are not orphaned in source.

Use it only for bounded Lens core bug reports that need an isolated feature branch, focused validation, and PR handoff.
